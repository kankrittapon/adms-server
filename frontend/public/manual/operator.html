📋 คู่มือ Operator (ธุรการ / กำลังพล)

งานประจำวัน: บันทึกลา · ดูยอด · ดูแลข้อมูลกำลังพล

1. เข้าระบบ

  1. เปิด http://192.168.1.248:8082 ใช้ชื่อผู้ใช้ของตัวเอง (ห้ามใช้บัญชีคนอื่น — ระบบเก็บประวัติว่าใครแก้อะไร)
  2. เปลี่ยนรหัสผ่านได้ที่เมนู ระบบ

2. หน้าแรก (Dashboard)

ยอดวันนี้ มา / สาย / ลา / ราชการ / ขาด / ยังไม่สแกน, กราฟ 7 วัน, ความพร้อมการลงนิ้ว และตารางแยกแผนก — กดที่การ์ดเพื่อดูรายชื่อ

ก่อน 9 พ.ย. 2569 จะมีแถบ 🧪 ทดลอง — คำว่า "ขาด" ช่วงนี้ยังไม่ใช่ของจริง

3. บันทึกลา / ไปราชการ (ทีละรายการ)

  1. เมนู บันทึกลา → เลือกกำลังพล (พิมพ์ชื่อค้นหา)
  2. เลือกประเภท: ลาป่วย, ลากิจ, ลาพักผ่อน, ลาคลอดบุตร, ลาอุปสมบท, ไปราชการ, ไปช่วยราชการ, ไปศึกษา/อบรม
  3. ใส่วันเริ่ม–วันสิ้นสุด · ประเภทราชการ/ช่วยราชการ/ศึกษา ต้องใส่เลขที่คำสั่ง · กดบันทึก
  • ไม่มีขั้นอนุมัติ — ใบลาที่ผู้บังคับบัญชาลงนามแล้วบันทึกได้ทันที
  • บันทึกผิด: กด ยกเลิก ที่รายการนั้นแล้วใส่เหตุผล (ไม่ลบ เก็บประวัติไว้)
  • ช่วงวันทับกับรายการเดิมของคนเดียวกัน ระบบจะไม่ให้บันทึก

4. นำเข้าการลาจาก Excel (หลายรายการ)

  1. หน้า บันทึกลา → การ์ด "นำเข้าการลาจาก Excel" → ⬇ ดาวน์โหลดแบบฟอร์ม
  2. กรอกในไฟล์: รหัสกำลังพล (หรือชื่อ-สกุล), ประเภท (ภาษาไทย), วันเริ่ม/วันสิ้นสุดแบบ 10/11/2569, เลขที่คำสั่ง, สถานที่, หมายเหตุ
  3. แถวขึ้นต้นด้วย # คือแถวตัวอย่าง ระบบข้ามให้
  4. Save As → CSV UTF-8 → อัปโหลด → ระบบตรวจทุกแถว (ยังไม่บันทึก)
  5. ผ่านทั้งหมดแล้วจะมีปุ่ม บันทึก N รายการ · ถ้ามีแถวแดง ให้แก้ไฟล์แล้วอัปโหลดใหม่

5. ยอดประจำวันและรายงานรายเดือน

เมนูใช้ทำอะไร
ยอดประจำวันรายชื่อทุกคนกับสถานะวันนี้ (หรือเลือกวันอื่น) แยกแผนก
รายงานรายเดือนตาราง 1 แถว/คน 1 ช่อง/วัน · ปุ่ม ส่งออก Excel

รหัสในรายงาน: ม มา · ส สาย · ล ลา · ร ราชการ · ย ยกเว้นสแกน · น ยังไม่ลงนิ้ว · ข ขาด

6. ข้อมูลกำลังพล

  • เมนู กำลังพล → กดชื่อ → แก้ไขข้อมูล: ยศ, ชื่อ, ชื่อภาษาอังกฤษ, ตำแหน่ง, แผนก
  • ชื่ออังกฤษจำเป็น — ใช้สร้างชื่อบนเครื่องสแกน เมื่อแก้ยศ/ชื่ออังกฤษ ชื่อบนเครื่องจะอัปเดตเอง
  • แผนกเลือกจากรายการ (ถ้าไม่มีแผนกที่ต้องการ แจ้ง Admin เพิ่ม)
  • แก้ทีละมากๆ: ส่งออก Excel → แก้ → นำเข้า (ระบบให้ตรวจก่อนบันทึก)
การลงนิ้ว ยกเว้นสแกน วันหยุด และย้ายออก เป็นงานของ Admin
