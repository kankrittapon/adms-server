👤 คู่มือกำลังพล

สำหรับทุกคนที่ต้องสแกนนิ้ว · อ่าน 2 นาที

1. สแกนนิ้วทุกเช้าวันทำการ

  1. วางนิ้วที่ลงทะเบียนไว้บนเครื่องสแกน รอจนเครื่องแสดงชื่อ/เสียงยืนยัน
  2. สแกน ระหว่าง 06:30 – 11:00 เท่านั้น
    • ถึง 10:00 = มา
    • 10:01 – 11:00 = สาย
    • หลัง 11:00 หรือไม่สแกน = ขาด (สแกนนอกช่วงเวลาเครื่องรับ แต่ไม่นับ)
  3. สแกนครั้งเดียวพอ ถ้าไม่แน่ใจสแกนซ้ำได้ ระบบใช้ครั้งแรกในช่วงเวลา
วันเสาร์–อาทิตย์และวันหยุดราชการไม่ต้องสแกน

2. ลา / ไปราชการ / ช่วยราชการ

  • ยื่นใบลาตามปกติ (ผู้บังคับบัญชาลงนาม) แล้ว ส่งให้ธุรการ/กำลังพลบันทึกในระบบ — วันที่บันทึกไว้จะไม่นับขาด
  • ไปราชการ/ช่วยราชการ ต้องมี เลขที่คำสั่ง แจ้งธุรการพร้อมช่วงวัน
  • ถ้าลืมแจ้ง แล้วถูกนับขาด แจ้งธุรการบันทึกย้อนหลังได้ ยอดจะแก้ให้อัตโนมัติ

3. ลงลายนิ้วมือครั้งแรก (ทำกับ Admin)

  1. นัด Admin ที่เครื่องสแกน — Admin เปิดรายการของคุณในระบบก่อน
  2. ที่เครื่อง: Menu → User Mng → เลือกชื่อของคุณ → Edit → Enroll FP
  3. วางนิ้วเดิม 3 ครั้งตามที่เครื่องบอก (แนะนำนิ้วชี้ขวา)
  4. Admin ให้คุณ ทดลองสแกน 1 ครั้ง เพื่อยืนยันว่าระบบจับคู่ชื่อถูก
เริ่มนับมา/ขาด วันถัดไปหลังลงนิ้ว · เมนูบนเครื่องอาจสะกดต่างเล็กน้อยตามรุ่น

4. ปัญหาที่พบบ่อย

อาการทำอย่างไร
สแกนแล้วเครื่องไม่รู้จักลองนิ้วเดิมอีกครั้ง กดให้เต็มนิ้ว ถ้ายังไม่ได้แจ้ง Admin ลงนิ้วใหม่
ชื่อบนเครื่องผิดแจ้งธุรการแก้ยศ/ชื่ออังกฤษ ระบบอัปเดตชื่อบนเครื่องให้เอง
สแกนแล้วแต่ขึ้นขาดเช็กว่าสแกนในช่วง 06:30–11:00 และเป็นวันหลังลงนิ้ว แจ้งธุรการตรวจ
