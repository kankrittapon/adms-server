🛠 คู่มือ Admin

ทำได้ทุกอย่างของ Operator (ดูคู่มือ Operator) บวกงานด้านล่าง

1. งานแยกกัน 4 อย่าง

งานที่ไหน
ลงเวลา (สแกนทุกเช้า)อัตโนมัติ — เครื่อง → ระบบ
ลงลายนิ้วมือคนใหม่เมนู ลงทะเบียนนิ้ว
ปรับรายชื่อ/ยศเมนู กำลังพล (Operator ทำได้)
ย้ายเข้า / ย้ายออกหน้ากำลังพลรายคน → ย้ายเข้า = ลงนิ้วใหม่ · ย้ายออก = ปิดบัญชีและลบนิ้วจากเครื่อง

2. ลงลายนิ้วมือ (4 ขั้น)

  1. เลือกคน — ต้องมีชื่ออังกฤษก่อน (กรอกได้ในหน้าลงนิ้วเลย)
  2. สร้างบัญชีบนเครื่อง — ระบบส่งชื่อไปที่เครื่องสแกน
  3. ให้เจ้าตัวลงนิ้วที่เครื่อง: Menu → User Mng → เลือกชื่อ → Edit → Enroll FP → วางนิ้ว 3 ครั้ง
  4. ทดลองสแกน 1 ครั้งภายในเวลาที่กำหนด → ระบบยืนยันและผูกบัญชีกับคน
หมดเวลาทดลองสแกน: กด เปิดรอสแกนใหม่ ได้ · เริ่มนับมา/ขาดวันถัดไปหลังลงนิ้ว

3. ยกเว้นการสแกน

  • หน้ากำลังพล → เลือกหลายคน → ตั้งยกเว้นสแกน หรือในหน้าคนนั้น → การ์ด "นโยบายการสแกน"
  • เหตุผลสำเร็จรูป: การเงิน, สำนักงานผู้บังคับบัญชา, ไปราชการ, ไปช่วยราชการ
  • คนที่ยกเว้นไม่ต้องลงนิ้ว และแสดงเป็น "ปฏิบัติหน้าที่" (รหัส ป) ในยอดและรายงาน · พลทหารไม่อยู่ในระบบลงเวลาอยู่แล้ว
  • ไปราชการระยะสั้น: ใช้การบันทึกลาประเภทไปราชการแทนการยกเว้น

4. วันหยุดราชการ

  1. หน้า บันทึกลา → ปฏิทินวันหยุด
  2. ปุ่ม เติมวันหยุดวันที่ตายตัวของปี ใส่ 14 วันให้ทันที
  3. วันพระ (มาฆะ วิสาขะ อาสาฬหะ เข้าพรรษา) และวันหยุดพิเศษ ครม.: กดวันในปฏิทิน → พิมพ์ชื่อ → เพิ่ม · กดวันสีแดงเพื่อลบ
ถ้าไม่ใส่วันหยุด ทุกคนจะถูกนับขาดในวันนั้น — ตั้งให้ครบทั้งปีล่วงหน้า

5. หน้าระบบ

การ์ดใช้ทำอะไร
โหมดเริ่มนับวันเริ่มนับจริง (ตอนนี้ 9 พ.ย. 2569) — ก่อนวันนั้นเป็นทดลอง ข้อมูลไม่ถูกลบ
รายชื่อแผนกเพิ่ม/ลบ/เรียงแผนกในตัวเลือกของฟอร์มกำลังพล แล้วกด บันทึก
รายงาน Telegramดูตัวอย่าง / ส่งทดสอบ · ส่งอัตโนมัติวันทำการ 11:05
บัญชีผู้ใช้สร้าง/ปิดบัญชี · Role: VIEWER ดูอย่างเดียว · OPERATOR บันทึกลา/แก้ข้อมูล · ADMIN ทุกอย่าง
เปลี่ยนรหัสผ่านของบัญชีตัวเอง

6. เครื่องสแกน

  • ออฟไลน์เกิน 30 นาที ระบบแจ้ง Telegram · ระหว่างออฟไลน์ การสแกนเก็บในเครื่องและดึงเข้าเมื่อกลับมา
  • เวลาบนเครื่องระบบตั้งให้อัตโนมัติ
  • ชื่อบนเครื่องไม่ตรง: หน้ากำลังพลมีแถบเตือน → กด ซิงก์ชื่อ

7. ลำดับก่อนเริ่มใช้งานจริง

  1. วันหยุดครบทั้งปี
  2. ชื่ออังกฤษ + แผนกครบทุกคน
  3. ตั้งยกเว้นสแกน (การเงิน, สำนักงาน ผบ.)
  4. บันทึกคนที่ไปราชการ/ช่วยราชการอยู่
  5. ลงนิ้วคนที่เหลือ — ดูเปอร์เซ็นต์ที่หน้าแรก
