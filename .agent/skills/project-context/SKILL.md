# Skill: Project Context

For a new session/model:
1. Read root `AGENTS.md`.
2. Read relevant `.agent/context/`.
3. Read canonical docs.
4. Read latest relevant checkpoint/report.
5. Load model adapter.
6. Identify current PromptID/mode.
7. Verify critical live state before WRITE.

Previous-agent prose is context, not current live proof.
