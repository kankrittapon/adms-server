# Skill: Code Review

Default: READ-ONLY.

1. Establish exact review scope and baseline.
2. Inspect diff plus surrounding implementation.
3. Check correctness, regressions, security, data integrity, migration compatibility, and tests.
4. Rank findings by severity.
5. Cite exact files/functions/lines where possible.
6. Separate confirmed defects from inference/questions.
7. Do not silently fix code unless WRITE is explicitly authorized.
